# Лабораторная работа №2 (Оценка «4»)
## Автор: Сукманова Анастасия, ИТ-1,2-2025 БН

### Описание проекта
Программа вычисляет произведение двух матриц в многопоточном режиме.
Реализованы две версии:

Базовая (на «3»): обычные матрицы, статическое распределение строк, вывод прогресса, замер времени. Включает режим оптимизации порядка циклов (для проверки влияния кэша).

Продвинутая (на «4»): матрица A — нижнетреугольная, генерация вынесена в отдельный процесс (IPC через Pipes), реализовано динамическое распределение строк между потоками.

### Структура файлов
1. MatMul.java — главный класс (запуск программы, замеры, проверка результатов).

2. Worker.java — поток для статического распределения.

3. WorkerDynamic.java — поток для динамического распределения.

4. MatrixGenerator.java — отдельный процесс для генерации матриц и передачи их через каналы.

### Инструкция по сборке и запуску

Шаг 1. Компиляция

Откройте терминал в папке с исходными файлами (там, где лежат .java) и выполните:
javac *.java

Шаг 2. Запуск

Общий синтаксис команды:

java MatMul <n> <m> <k> <T> [bench] [mode]

Где:
n, m, k — размеры матриц (для треугольной матрицы n должно быть равно m);

T — количество потоков;

bench (необязательно) — режим «чистых замеров» (отключает вывод прогресса и проверку корректности);

mode (необязательно) — режим распределения: static (по умолчанию) или dynamic.

### Примеры запуска:

Демонстрация работы на «3» (с прогрессом и проверкой):

java MatMul 500 500 500 4

Замер времени в режиме статики (на «4»):

java MatMul 1500 1500 1500 8 bench static

Замер времени в режиме динамики (на «4»):

java MatMul 1500 1500 1500 8 bench dynamic

### Примечания

Для работы межпроцессного взаимодействия (IPC) команда java должна быть доступна в системной переменной PATH (при запуске из терминала IDE это работает автоматически).

Для тестирования влияния кэша на матрице 1500 при запуске без флага bench и T=1 программа дополнительно выведет сравнение времени для порядков циклов i->j->t и i->t->j.

В режиме bench выводятся только время выполнения и контрольная сумма (Checksum), что необходимо для точных замеров.
